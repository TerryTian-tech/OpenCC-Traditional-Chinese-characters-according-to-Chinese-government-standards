# 《通用规范汉字表》规范繁体转换方案设计说明

由于本转换方案目前收录的异体字数量已经远远多于《通用规范汉字表》附件1《规范字与繁体字、异体字对照表》所收录的异体字数量，因此有必要说明本转换方案的设计目的、异体字收录原则，以及转换方案预期转换目标和设计原则。

在使用转换程序前，请务必查阅[「规范繁体字形转换器」当前版本临时勘误表](https://github.com/TerryTian-tech/OpenCC-Traditional-Chinese-characters-according-to-Chinese-government-standards/blob/main/doc/%E3%80%8C%E8%A7%84%E8%8C%83%E7%B9%81%E4%BD%93%E5%AD%97%E5%BD%A2%E8%BD%AC%E6%8D%A2%E5%99%A8%E3%80%8D%E5%BD%93%E5%89%8D%E7%89%88%E6%9C%AC%E4%B8%B4%E6%97%B6%E5%8B%98%E8%AF%AF%E8%A1%A8.md)，知悉仓库内最新转换程序发行版与转换方案的差异。

另请使用者注意，目前的规范繁体转换方案与《古籍印刷通用字规范字形表》（GB/Z 40637—2021）并不兼容，这一不兼容本身源于《古籍印刷通用字规范字形表》与《通用规范汉字表》在字形上矛盾。从两表自身规定的适用范围上而言，《通用规范汉字表》附件1 与《古籍印刷通用字规范字形表》均可适用于繁体书刊和古籍的印刷，只是由于 README 中所述原因，前者的使用人数远超过后者。如果有转换该表字形的需要，可以考虑使用GitHub项目 [GujiCC](https://github.com/forfudan/GujiCC) 并安装特定字体如 [方正古籍规范宋](https://www.foundertype.com/index.php/FontInfo/index/id/6659) 或 [源古黑体](https://zhuanlan.zhihu.com/p/1897044158293717296) 等。

## 1. 术语界定

**规范繁体字** 指被《通用规范汉字表》收录的规范繁体字形，包括：

- 《通用规范汉字表》附件1《规范字与繁体字、异体字对照表》所指定的繁体字形；
- 未在《通用规范汉字表》附件1中被指定繁体字形，但被《通用规范汉字表》的一级/二级/三级字表收录的规范字，视为繁、简一致的字形。

**异体字**  指与《通用规范汉字表》规定的规范字的字音和字义相同，但是字形不同，原则上应当停止使用的字形。1955年《关于发布第一批异体字整理表的联合通知》规定：“从实施日起，全国出版的报纸、杂志、图书一律停止使用表中括弧内的异体字。但翻印古书须用原文原字的，可作例外。……停止使用的异体字中，有用作姓氏的，在报刊图书中可以保留原字，不加变更，但只限于作为姓用。”现行法规虽有大幅放宽（例如允许在文物古迹展览、书法艺术作品、姓氏、题词招牌中使用，允许在出版、研究、教学时确有需要而使用），但仍有“不倡导使用”之义。

《通用规范汉字表》研制组成员张书岩在《〈规范汉字表〉对异体字的确定》（《语言文字应用》2005年第1期）一文中提出：
> 对古籍中的异体字，可分三个层次对待。普及性的古汉语读物，一律使用规范的正字，不使用异体字；供一般人阅读的古籍，基本上使用规范正字，也可根据需要，使用部分异体字；供专门研究用的古籍，不受《规范汉字表》规定的限制。

《通用规范汉字表》附件1《规范字与繁体字、异体字对照表》指定了一批异体字，从所收录的范围来看，“异体字”的概念还包含了《古籍印刷通用字规范字形表》（GB/Z 40637—2021）在“术语和定义”所称的“异写字”和“局域异体字”。《古籍印刷通用字规范字形表》将“异写字”界定为“在同一形制下，记录同一个词，构形和意义相同，仅仅是写法不同的字。”按这一定义，《通用规范汉字表》指定的异体关系如“删—刪”“跺—跥”（构件写法不同而导致差异）和“峰—峯”（构件位置不同而导致差异）均属此类。“局域异体字”被界定为“在某一时期曾经是异体字，但在不同时代的古籍中又有不同用法的字。”《通用规范汉字表》附件1通过注释专门限制了部分异体字的使用范围，如“蒐”在用于表示草名和春天打猎时作为规范字使用，其余义项则作为“搜”的异体字形。

**表外异体字**  指并非《通用规范汉字表》附件1《规范字与繁体字、异体字对照表》所指定的异体字，但是仍然符合“与《通用规范汉字表》规定的标准字的字音和字义相同，但是字形不同，原则上应当停止使用的字形。”定义的非标准字形。国家语委负责人在《通用规范汉字表》正式颁布后[接受采访](https://www.chinanews.com/cul/2013/09-04/5242568.shtml)时表示：“……语文辞书的收字量根据其服务领域和使用对象不同，可以部分或全部收录《通用规范汉字表》中的字，也可以适当多收一些备查的字。”其后，《现代汉语词典》《新华字典》在落实《通用规范汉字表》进行修订时，加入了“表外异体字”这一概念，将部分《通用规范汉字表》未指定的异体字也加入词条标识的异体字中。

除了直接被标识出的“表外异体字”外，内地的繁体出版原则上还要求应当将“旧字形”转换成为“新字形”。中国内地的辞书如《汉语大词典》《现代汉语词典》都附有《新旧字形对照表》，用于读者和出版行业去对照改正汉字规范化前的部分旧印刷字形。如“彔”按照内地的规范，印刷体应为“录”，则以“彔”构形的“錄、祿”亦应转换为“録、禄”。本转换方案亦将“旧字形”视之为广义的“表外异体字”的一部分。

关于异体字标准在文本编辑中的实际适用问题，参见[《通用规范汉字表》附件1 与《古籍印刷通用字规范字形表》的异体标准适用问题](https://github.com/TerryTian-tech/OpenCC-Traditional-Chinese-characters-according-to-Chinese-government-standards/blob/main/doc/%E3%80%8A%E9%80%9A%E7%94%A8%E8%A7%84%E8%8C%83%E6%B1%89%E5%AD%97%E8%A1%A8%E3%80%8B%E9%99%84%E4%BB%B61%E4%B8%8E%E3%80%8A%E5%8F%A4%E7%B1%8D%E5%8D%B0%E5%88%B7%E9%80%9A%E7%94%A8%E5%AD%97%E8%A7%84%E8%8C%83%E5%AD%97%E5%BD%A2%E8%A1%A8%E3%80%8B%E7%9A%84%E5%BC%82%E4%BD%93%E6%A0%87%E5%87%86%E9%80%82%E7%94%A8%E9%97%AE%E9%A2%98.md)。

**类推简化字**  指依据《简化字总表》第二表中所列已简化字及已简化偏旁，对《简化字总表》第三表未予收录的汉字自行“类推”简化所得的字形。1964年《关于简化字的联合通知》中规定，含有已简化偏旁的字“应该同样简化”，又规定“类推出来的简化字，将收入中国文字改革委员会编印的《简化字总表》中。”后来在《〈简化字总表〉说明》中对类推简化作出明确的规定：“未收入第三表的字，凡用第二表的简化字或简化偏旁作为偏旁的，一般应该同样简化。”这便是类推简化字的由来。

2009年发布的《通用规范汉字表（征求意见稿）》，在《〈通用规范汉字表〉说明》中规定：“根据国务院1986年‘今后对汉字的简化应持谨慎态度，使汉字的形体在一个时期内保持相对稳定’的指示精神，本字表以外的字，不再类推简化。”2013年《通用规范汉字表》正式版本虽删去此句，但教育部语言文字信息管理司组编、王宁主编的《〈通用规范汉字表〉解读》又规定：“《通用规范汉字表》根据国务院1986年‘今后，对汉字简化应持谨慎态度，使汉字的形体在一个时期内保持相对稳定’的指示精神，对类推简化采取了严格掌握的原则，一般不再扩大类推的范围；但考虑到汉字应用的现实，也收录了少数已经被社会所习用，并符合《简化字总表》规定的类推简化字。今后表外字不再类推。”（商务印书馆2013年版，第47页）绝大多数此类“类推简化字”亦未获采纳为规范字形。因此，《通用规范汉字表》未收录的类推简化字在现行出版规范下不宜使用。除《通用规范汉字表》已采纳为规范字的类推简化字外，本转换方案仅采纳《现代汉语词典》《新华字典》已收录的少量类推简化字的转换，其余类推简化字不在转换范围之内。

## 2. 异体字收录原则

本转换方案转换预期达到的目标为： **当用户键入非《通用规范汉字表》标准的繁体文本时，转换程序应返回符合《通用规范汉字表》标准的繁体文本。** 这意味着本转换方案所采纳的异体关系数量将大大超出《通用规范汉字表》附件1所收录的异体字数量。尤其考虑到内地出版的繁体文本多数为古籍，古籍内存在大量俗字、讹字需要处理为《通用规范汉字表》所收的规范繁体字形，如果只采纳《通用规范汉字表》附件1所收录的不足1000组异体字转换关系，将无法处理这些非规范字，造成编辑校对和阅读理解上的困难。

**基于此，本转换方案采纳了上文所述的“异体字”转换关系外，还大量采纳了“表外异体字”转换关系。** 本转换方案所采纳的“表外异体字”主要来源为：

- 《现代汉语词典》《新华字典》收录的“表外异体字”；
- 《现代汉语词典》《汉语大词典》所附《新旧字形对照表》所收字，以及依据该表“旧字形”所构形的字；
- OpenCC 开源项目转换字表中已经收录的异体字转换关系；
- 在古籍编辑校对领域中已经公认无疑义、可以径改为规范字的俗字、讹字（特别感谢易建鹏老师和胡馨媚老师提出的意见）；
- 商务版《古代汉语词典》收录的异体字。

以上异体字数据并非全然无条件采纳到本转换方案中。

**如果存在下列情形，任何“表外异体字”数据原则上不会被采纳：**

- 异体字存在部分义项无法为规范字覆盖，实际上是局域异体关系的；
- 异体字存在“一对多”的异体对应关系；
- 异体字本身是《通用规范汉字表》所收录的规范字（如《古代汉语词典》收录的沉—沈、案—桉这类异体关系）。

**如果之前的工作中此类“表外异体字”被错误采纳进入转换方案的字表，后面亦会修订剔除，或在极少数情况下限定在某些词组转换中使用。**

> [!NOTE]
>目前部分“表外异体字”的数据包含了《通用规范汉字表》既未收录异体字形也未收录规范字形的异体关系，截至2026年10月21日，这样的异体关系有56组被收录到本转换方案中。详见[《〈通用规范汉字表〉表外正字的转换》](https://github.com/TerryTian-tech/OpenCC-Traditional-Chinese-characters-according-to-Chinese-government-standards/blob/main/doc/%E3%80%8A%E9%80%9A%E7%94%A8%E8%A7%84%E8%8C%83%E6%B1%89%E5%AD%97%E8%A1%A8%E3%80%8B%E8%A1%A8%E5%A4%96%E6%AD%A3%E5%AD%97%E7%9A%84%E8%BD%AC%E6%8D%A2.md)所列。

此外，**出于转换后的文本应当文义正确、不应出现文本错误这一考虑，本转换方案亦不会完全采纳《通用规范汉字表》附件1所收的异体关系。** 如果《通用规范汉字表》中所收的异体字存在以下情况，本转换方案**将不会采用该异体关系，或在极少数情况下作为“一对多”的转换进行变通处理：**

- 异体字只有部分义项适用异体关系，部分常用的义项无法为规范字覆盖。如《通用规范汉字表》以“椷”为“缄”的异体字形，但只有“椷”作“信函”义时，才可以改作“缄”，作为“杯”的义项、作为“包含”的义项改成“缄”会出现文本错误；
- 异体字存在一对多的异体关系。如《通用规范汉字表》规定“閒”为“闲”的异体字形，但实际上“閒”亦是“间”的异体字形；《通用规范汉字表》规定“璿”为“璇”的异体字形，但实际上“璿”亦为“琼”的异体字形；“彊”不仅是“强”的异体，也可以作“疆”的异体，而《通用规范汉字表》只规定了“强—彊”；等等；
- 《辞海》或《现代汉语词典》已经采纳为规范字形、拥有独立词条的字（比如 **菑、紬、並、謟、鰌、鬨** 等字）。

为了文本的正确性而放弃转换某些《通用规范汉字表》所定的异体字，这种转换原则是与[《OpenCC 设计思想》](https://github.com/BYVoid/OpenCC/blob/master/DESIGN_PRINCIPLES.md)的 “避免过度转换” 一节一致的：

> OpenCC 的另一個重要原則是：避免過度轉換。
>
> 當某個字或詞存在歧義，而無法可靠判定語義時，OpenCC 傾向於保持原文，而不是進行高風險轉換。
>
> 例如：
>
> * `沉` / `沈`
> * 某些情況下的 `干` / `幹` / `乾`
> * 某些情況下的 `发` / `發` / `髮`
>
> 這種設計意味著：
>
> * 某些本可轉換的情況可能不被轉換（較低 recall）；
> * 但已發生的轉換通常具有較高可信度（較高 precision）。
>
> 這一策略可能導致部分使用者認為「轉換不完整」，但其目的在於降低錯誤轉換的概率，避免因誤判語義而產生更嚴重的錯誤結果。

**在具体的词语用字上，目前的转换一律参考《现代汉语词典》（第7版）对 OpenCC 词库进行修订。比如“面向講臺”，按照《现代汉语词典》的义项解释，规范繁体应为“面嚮講臺”，则依照《现代汉语词典》进行转换。** 目前的转换词库尚未修订的，未来亦会照此进行修改。

自 1.4.6 版本开始，本仓库的繁体转换为规范繁体、简体转规范繁体两个转换方案，根据龙伟业老师[《困境·症结·对策——现代汉字规范与古籍整理》](https://mp.weixin.qq.com/s/o5yyiMWNhvERikOOZG0oAg)一文作出了全面修订，新增“古籍整理时保留异体字例外”一项，使用者可以前往 GitHub 仓库中的字表查看注释。这批例外异体字不影响「规范繁体字形转换器」的默认转换行为，但是会在「规范繁体字形转换器」的“文字转换”选项卡中作为候选字显示。

## 3. 主要转换方案设计原则

**繁体转换为规范繁体**  本规范繁体转换方案主打的转换模式。转换目标主要针对内地的繁体稿件、古籍整理稿件，不仅会转换异体关系，同时也会转换简—繁关系中所有“一对一”能转换的字（根据龙伟业老师[《困境·症结·对策——现代汉字规范与古籍整理》](https://mp.weixin.qq.com/s/o5yyiMWNhvERikOOZG0oAg)一文有所调整），以解决内地繁体稿件中繁简混杂的问题。

**只转换繁体旧字形到新字形**  只转换《汉语大词典》所附《新旧字形对照表》所收旧印刷体字，以及依据该表“旧字形”所构形的字，兼转换部分古籍中出现的字形相近的俗字、讹字。这一模式同时也会转换简—繁关系中所有“一对一”能转换的字，以解决内地繁体稿件中繁简混杂的问题。大部分异体字均不转换。这一模式针对的是更复杂的繁体稿件，如古诗文集，需要用户保留异体字自己来判断的情况。

**繁体转简体**  转换繁体字和异体字为《通用规范汉字表》所收简体字，在原 OpenCC 字表和词库基础上修订而成。这一方案剔除了原 OpenCC 字表中大部分位于《通用规范汉字表》表外的类推简化字，因为《通用规范汉字表》的表外字一般不再类推简化，除了个别为《现代汉语词典》《新华字典》采纳的可用于出版，大部分类推简化字原则上不再提倡使用。

**只将异体字转换为简体** 转换异体字为《通用规范汉字表》所收简体字，不作其他转换。

**简体转规范繁体**  根据《通用规范汉字表》附件1将简体字转换为规范繁体字，在原 OpenCC 字表和词库基础上修订而成。简—繁对应关系根据龙伟业老师[《困境·症结·对策——现代汉字规范与古籍整理》](https://mp.weixin.qq.com/s/o5yyiMWNhvERikOOZG0oAg)一文有所调整。

在实务上，真实文本未必严格符合《通用规范汉字表》所规定的简体，所以简体转规范繁体方案，采用了部分 OpenCC 原简转繁字表收录的类推简化字转繁体映射。不在这一字表内的其他类推简化字，推定为使用频率较低，不纳入简体转规范繁体方案，这点与 GitHub 上另一个活跃方案 [opencc-tonggui](https://github.com/amorphobia/opencc-tonggui) 不同。原 OpenCC 字表中“类推简化字转换后成异体字”的规则，亦一概删去，这些类推简化字和其他未收录的类推简化字一样，在转繁操作后会继续保留在稿件中，留待出版人员三审三校去解决。

## 4. 相关讨论

关于异体字收录标准与相关转换原则，曾在多个 issue 中反复讨论，例如：

- [#5](https://github.com/TerryTian-tech/OpenCC-Traditional-Chinese-characters-according-to-Chinese-government-standards/issues/5)：类推简化字“𪨧”的转换问题。OpenCC 原有的简—繁转换字表中存在“𪨧—崙”的映射，但“崙”为《通用规范汉字表》规定的异体字，所以本仓库的简转繁方案删去了该组映射。此外，类推简化字到繁体的转换，只以 OpenCC 原简转繁字表收录的为限，其他使用频率较低的类推简化字不纳入简转繁方案。除开简转繁方案的这一特例，其他转换方案不考虑规范字以外的类推简化字的转换（《现代汉语词典》《新华字典》已收录的少量类推简化字，酌情采纳）。

- [#10](https://github.com/TerryTian-tech/OpenCC-Traditional-Chinese-characters-according-to-Chinese-government-standards/issues/10)：“于”“於”的转换问题。“於”“于”在内地的文字规范中有着复杂的调整历史。“於”曾被规定为“于”的繁体形态，后来又被规定为异体字，再后来又被调整为规范字。《现代汉语词典》（第7版）的首选推荐是用“于”，但是繁体文本中出现“於”代替“于”的情况非常普遍。《现代汉语词典》认为“於”的义项同“于1”，即词典编撰者认为可以在“于”的大部分义项上使用“於”，但是不是他们的首选推荐。既然“于”“於”都被认为是规范字，将“于”转换成“於”、“於”转换成“于”等具有争议的转换映射就不应该存在，转换时应保留文本的原始用法，留待文本的编辑者按照自己的偏好去处理即可。
